# 《宿舍规则怪谈》首轮正式视觉设计

## 目标

为已完成的七章与八个结局建立一套只属于新男生宿舍基线的首轮正式视觉资产，并以可回退映射接入现有视觉小说运行时。

## 范围与边界

- 仅使用 `assets/stories/dormitory-namefloor/formal/`；不删除或引用 `dormitory-rollcall` 的 Legacy 女生宿舍资产。
- 交付七名可复用角色母版、核心状态变体、可复用 9:16 背景、手机/档案媒体、关键道具和八张结局关键画面。
- 手机的玩家可见中文消息、规则、时间和账号文字仍由 HTML/CSS 渲染；图片只承载硬件、头像、照片或无文字介质。
- 所有正式路径具有 CSS/程序化视觉回退；加载失败不会阻止推进、存档、返回书架或切换《雨夜来电》。
- 不改动剧情节点、状态字段、八结局条件或语音资源。

## 美术与连续性

画面为 9:16、写实中国大学男生宿舍恐怖视觉小说。基调是午夜手机冷光、偏绿荧光、冷白应急灯和晨光；红色只作为红马甲/危险信号。角色母版作为变体的唯一参照：林峰灰色旧 T 恤，周朝阳低饱和橄榄上衣，谷雨褪色姜黄短袖，宋明米白短袖与青绿色条纹毛巾，吴阿姨旧绿色马甲。所有人物为真实中国人脸，避免动漫、校服、文字、水印和 Legacy 角色。

## 运行时架构

`formal/visual-manifest.js` 只声明文件路径、尺寸、透明度、来源与加载优先级。`story-asset-map.js` 将已有场景、角色、结局条目映射到这些资产，保留现有 scene class、safe zone、effects 与 missing-formal-image 回退结构。`runtime-visuals.css` 在正式图可用时提供背景、角色及手机媒体层，在资源错误时保留原样板构图。

## 验收

新增静态检查验证：正式文件均非空、只有新命名空间、manifest 与 map 路径一致、八个结局各有独立图、无 Legacy 人物标识、手机文字未烘焙为 UI 文本契约。运行现有七章/结局/多故事/移动端/特效生命周期检查；浏览器四尺寸检查作为人工签核记录，不以自动化替代。
